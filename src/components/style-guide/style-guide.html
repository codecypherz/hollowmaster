The word "Geo" is never set beside a number — the mark names the currency, and carries that name for assistive technology, so an amount inside a control needs no label of its own.

Sealed packs

One renderer draws every pack the application shows. A wrapper is crimped top and bottom, its artwork fills the face between the crimps centred and uncropped on one side more than the other, a sheen travels across it, and a gold trim binds its edge. The tier name is printed on the wrapper itself over a scrim band, never set beside it. Torn is the state an opening leaves a pack in: the same wrapper, its top seal broken. The narrowest example is the pack's minimum supported width of {{ packMinWidth }}px — nothing here renders one narrower — where the ornament simplifies but every part is still drawn.

Card states

One component renders all of these. Aspect ratio 2.5:3.5, four sections — name, image, stats, ability — with the chevrons inside the border but outside the sections, rarity on a five-slot star track, and stats as labelled bars that never show a numeral. The ability section is an enclosed box, bordered on all four sides and held off the face's edges, carrying the set and collector number on its plate. The frame's colour is ownership's and nothing else's: blue for the player, crimson for the opponent, neutral for a card in no one's hands.

Stat bars across the range

Each bar is a fixed label cap and the track it leaves behind, so the fill is a proportion of the track alone. At the bottom of the range the fill is narrower than the label and still wholly visible; at the top it runs the full track and the label still reads, because the two never share a box. No numeral appears anywhere.

Name fitting

A name is fitted, never cut. A short one is drawn at the default size; a longer one steps down until it fits, and wraps within the name row if the smallest step still will not hold it on one line. No ellipsis, no clipped glyph, and the row's height never moves — compare the image, stats, and ability sections across the three.
